# Pickle Garden - Promotional Web Application 🥒

A promotional web application built for **Pickle Garden at The Yards** (Ponte Vedra Beach, Florida).

Official Instagram: [@picklegarden_](https://www.instagram.com/picklegarden_/?hl=en)

---

## 🌟 Key Features

- **Interactive 12-Court Map & Status**: Visual court grid showing live status (Available, Drop-In, Booked) and Stadium LED Night Lighting toggle.
- **Online Court Booking System**: Multi-step interactive court reservation flow with time slots, player count, demo paddle rentals, and digital court pass generation.
- **Programs & Open Play**: Daily drop-in schedules, fundamental clinics, kitchen soft game bootcamps, and Friday Night Lights social events.
- **Garden Club Membership Portal**: Tier comparisons (Guest, Garden Club, VIP Championship) with interactive monthly/annual billing toggles (save 20%).
- **Certified Pro Coaching**: Spotlights on coaching staff with lesson booking CTAs.
- **Instagram Gallery Feed**: Embedded preview of `@picklegarden_` highlights with hover engagement metrics and lightboxes.
- **Player Skill Level Assessment Quiz**: Interactive 3-question quiz calculating player skill rating and recommending tailored clinics.
- **Location, Directions & Contact**: Venue amenities checklist (Pro Shop, Social Bar, Wi-Fi, Restrooms), interactive Google Map, and direct contact form.

- **Vite**
- **Tailwind CSS**

- **Framer Motion**

## 🚀 Quick Start

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```
